Комплексный анализ розничных продаж: от SQL-исследования данных до интерактивного дашборда с ABC-сегментацией клиентов, анализом маржинальности и географией продаж.

---

## 📌 Ключевые выводы

- 💰 **Выручка $142.4 млн**, прибыль $31.6 млн, средняя маржа **22.15%** за 2023–2024
- 🎯 **ABC-анализ клиентов:** 40% клиентов формируют 80% выручки — шире классического правила Парето (20/80), клиентская база менее концентрирована, чем принято ожидать
- ⚠️ **87 тысяч клиентов (72%)** совершили только одну покупку — существенный потенциал для программ удержания
- 📈 **Резкий рост продаж в Q4** — выручка подскакивает с ~$9 млн/мес до **$27.3 млн в ноябре**, устойчивая сезонность из года в год
- 🏆 **Electronics** — самая маржинальная категория, **Tempur-Pedic Mattress** — товар №1 по выручке ($9.06 млн)
- 🔍 Обнаружен клиент-выброс с выручкой ~$80 тыс. при 100+ заказах — кандидат для отдельного B2B-сегмента

## 🔍 SQL-техники в проекте

| Концепция | Файл | Что демонстрирует |
|---|---|---|
| `GROUP BY`, `HAVING` | 02, 04 | Агрегация с постфильтрацией |
| `DATE_TRUNC`, `LAG() OVER` | 03, 07 | Динамика продаж, рост месяц к месяцу |
| `CASE WHEN` | 05 | Категоризация товаров по марже |
| `RANK() OVER (PARTITION BY ...)` | 08 | Топ-продукты внутри категории |
| Коррелированный подзапрос / CTE | 09 | Товары выше среднего по категории |
| `HAVING COUNT(*) = 1` | 10 | Выявление клиентов с единственной покупкой |
| Многоуровневые CTE + `SUM() OVER` | 11 | ABC-анализ клиентской базы |

## 📊 Дашборд Power BI

![Дашборд продаж](file-001.png.png)

**KPI-обзор:** выручка, прибыль, маржа, количество заказов, доля клиентов с единственной покупкой, доля группы A.

**ABC-сегментация клиентов** — ключевой визуал: пончиковая диаграмма групп A/B/C, построенная через DAX (`RANKX`, вычисляемая таблица, накопительная доля выручки).

**Динамика продаж:** ступенчатый график выручки и прибыли по месяцам — чёткая сезонность с пиком в Q4.

**Категории и продукты:** гистограмма по категориям, топ-15 продуктов с условным форматированием по марже, treemap категория → подкатегория.

**География:** карта выручки по штатам США, матрица регион × категория с итогами.

**Клиентская аналитика:** точечная диаграмма сегментации клиентов по количеству заказов и выручке.
